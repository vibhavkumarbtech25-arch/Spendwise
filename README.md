# SpendWise — Student Finance Manager

SpendWise is a personal finance web application designed to help students track expenses, manage budgets, monitor savings goals, and understand their spending habits through interactive charts.

## Features

* **Dashboard:** View spending summaries, daily averages, and top spending categories.
* **Transaction Management:** Add, edit, delete, search, filter, and sort expenses.
* **Interactive Charts:** Visualize category-wise, daily, and monthly spending.
* **Savings Goals:** Create goals and track savings progress.
* **Recurring Expenses:** Manage repeating expenses.
* **Dark Mode:** Switch between light and dark themes.
* **Data Export:** Export transactions to CSV.
* **Backup and Restore:** Save and restore application data using JSON.
* **Local Data Storage:** Retain data in the browser using LocalStorage.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Chart.js

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Launch `index.html` using the Live Server extension.
4. Start adding transactions and tracking your expenses.

An internet connection may be required to load Chart.js if the project uses its CDN.

## Data and Privacy

SpendWise stores its application data in the browser's LocalStorage. Data is tied to the browser and website origin, so it does not automatically synchronize across devices. Export a backup before clearing browser data.
